# QuotaBar v0.1.15

## Fix

- Replaces SwiftUI `MenuBarExtra(.window)` with a manually managed AppKit `NSStatusItem` and `NSPopover`.
- Keeps the menu bar icon alive when the popover opens and closes.
- Avoids the macOS SwiftUI `AppWindowsController.WindowInfo.resolvedStyle` assertion path observed in the QuotaBar crash report.
- Keeps a Dock entry fallback if macOS hides the menu bar status item at the system level.
- Adds a source-level menu-bar host regression check and an AppKit popover open/close smoke test.
