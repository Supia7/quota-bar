## What's changed

- Adds in-app browser OAuth sign-in for Claude and Codex.
- Stores new access/refresh tokens in the macOS Keychain.
- Refreshes Keychain-backed credentials without launching Claude or Codex CLI.
- Keeps existing credential-file discovery and JSON selection as an explicit fallback.
- Saves a newly connected account only after one real quota response succeeds.
- Prevents duplicate provider accounts when the account identity or credential path matches.

## Sign-in flow

1. Open Settings.
2. Choose `Sign in with Claude` or `Sign in with Codex`.
3. Complete provider login in the browser.
4. Paste the callback URL or authorization code into QuotaBar.
5. QuotaBar exchanges the code, verifies one real quota response, stores tokens in Keychain, and adds the account.
