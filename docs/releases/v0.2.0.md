# QuotaBar v0.2.0

## Highlights

- Replaces the wide legacy monitor with a compact provider-first popover.
- Shows Codex and Claude as separate provider blocks with primary quota, reset time, and secondary windows.
- Adds local Today usage summaries for Claude and Codex session logs: token count and session count.
- Keeps local usage scanning independent from OAuth refresh and does not execute the CodeBurn CLI or require Node.
- Adds quota reset detection and a macOS notification/banner when a quota unexpectedly recovers.
- Keeps the stable AppKit `NSStatusItem` and `NSPopover` menu-bar host.

## OAuth and account handling

- Claude manual callback input accepts the authorization code before the display fragment.
- Claude token exchange uses the provider's form-encoded request contract.
- Claude nested account identity (`account.uuid` and `account.email_address`) is decoded safely.
- Codex loopback callback behavior remains unchanged.

## Privacy and licensing

- OAuth credentials remain in the macOS Keychain.
- Local usage reads only today's Claude/Codex JSONL records and does not retain message content.
- QuotaBar does not bundle or execute CodeBurn. The independent local analytics implementation is documented in `THIRD_PARTY_NOTICES.md`.
