## What's changed

- Adds a compact QuotaBar mascot icon inspired by the `ip-as-logo` style: a rounded lower-corner character with a visible quota bar.
- Packages the icon into the macOS app bundle so Finder, update dialogs, and release artifacts no longer show the generic placeholder icon.
- Prevents Sparkle from starting when QuotaBar is launched from a DMG, Downloads, or another temporary/read-only location.
- Offers to copy QuotaBar to `~/Applications` and relaunch it before enabling automatic update checks.
- Keeps Sparkle updates user-approved rather than silently replacing the executable.

## Update behavior

1. Install QuotaBar by dragging it from the DMG to `/Applications`, or accept the first-run move to `~/Applications`.
2. Relaunch QuotaBar from Applications.
3. Sparkle can then check the signed HTTPS appcast and install approved updates.

## Downloads

- **Apple silicon:** `QuotaBar-macos-arm64.dmg`
- **Intel:** `QuotaBar-macos-x86_64.dmg`
- **Universal update archive:** `QuotaBar-macos-universal.zip`
- `SHA256SUMS` verifies all downloadable archives.
