## What's changed

- Removes production sample accounts and example emails. A fresh install now shows a clear empty state until a real OAuth account is connected.
- Keeps sample data only in the explicit `QuotaBarPreview` development target.
- Replaces multi-line account cards with compact one-row summaries showing provider, account, email, and remaining quota badges.
- Moves reset times and progress bars behind an expand action so five accounts remain readable in a short monitor.
- Removes credential JSON discovery, JSON picker, and file-backed account registration. New accounts use browser OAuth and macOS Keychain only.
- Explains that the input is a callback URL or one-time authorization code, not an access or refresh token.
- Surfaces actionable OAuth exchange errors such as expired code and redirect mismatch without printing token values.
- Adds automatic UI localization for English, Korean, Japanese, Simplified Chinese, and Spanish.
- Updates all README language variants with the OAuth-only flow, compact UI behavior, and the QuotaBar mascot logo.

## Sign-in flow

1. Open Settings.
2. Choose `Sign in with Claude` or `Sign in with Codex`.
3. Complete the provider login in the browser.
4. Paste the complete callback URL, or the one-time authorization code. Do not paste an access/refresh token.
5. QuotaBar exchanges the code, verifies one real quota response, and stores tokens in macOS Keychain.
