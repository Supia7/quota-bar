# QuotaBar v0.1.14

## Changes

- Adds automatic Codex OAuth completion through the registered loopback callback at `http://localhost:1455/auth/callback`.
- Binds the callback listener to `127.0.0.1` only and validates the `/auth/callback` route.
- Returns a local browser confirmation page without displaying the authorization code.
- Falls back to the existing callback URL/one-time code paste flow if the local port is unavailable.
- Keeps Claude's fixed HTTPS callback flow explicit because its current redirect cannot be intercepted by the app.
- Adds a real loopback HTTP round-trip self-check and localized automatic-callback status/error messages.
