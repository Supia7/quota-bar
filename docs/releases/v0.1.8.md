## What's changed

- Adds Sparkle 2.9.6 with signed HTTPS appcast verification.
- Keeps automatic update installation disabled; the user approves each update.
- Adds a universal signed update archive and a signed appcast to the release workflow.
- Adds public artifact read-back checks for checksums, Developer ID signing, notarization, and Sparkle signatures.

## Upgrade note

v0.1.7 predates Sparkle. Install v0.1.8 once from the DMG; later versions can use the signed Sparkle update path.

## Downloads

- **Apple silicon:** `QuotaBar-macos-arm64.dmg`
- **Intel:** `QuotaBar-macos-x86_64.dmg`
- **Universal update archive:** `QuotaBar-macos-universal.zip` (used by Sparkle)
- `SHA256SUMS` verifies all downloadable archives.
